# 渲染与状态

## Vue 响应式更新

Vue 状态已改变但页面没有更新时，对照用户代码检查 ref 在脚本中是否通过 .value 读写、解构 reactive 是否丢失响应式连接，以及 computed 是否依赖真正变化的响应式数据。异步 DOM 观察可以建议在 nextTick 后比较结果；不要将 nextTick 当作修复错误数据流的通用手段。

## React 重复渲染

React 出现重复渲染时区分开发模式的额外检查与真正的更新循环。根据用户给出的 effect 依赖和 setter 调用，检查渲染期间更新状态、effect 写回自身依赖、每次渲染创建的新对象依赖。建议最小改动后说明期望的调用次数或状态变化，避免直接建议删除依赖数组。
