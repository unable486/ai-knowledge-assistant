# 浏览器运行时报错

## 页面白屏与异常堆栈

页面白屏时让用户提供控制台中的第一条错误和最靠近业务代码的堆栈位置。后续错误可能只是首个异常的连锁结果。若出现 undefined 或 null 的属性访问，检查报错对象在首次渲染时的实际值，再区分异步数据未返回、字段名称错误和条件分支漏判。提供初始值或条件渲染建议时说明它保护的生命周期阶段，不用可选链隐藏数据契约错误。

## 请求失败与界面表现

用户报告请求失败时，依据其提供的状态码、响应体和调用时机区分网络不可达、认证拒绝、服务端错误与响应解析失败。Network 面板中看到请求成功也不能证明组件拿到了预期字段；需要核对响应形状和状态赋值。没有这些材料时提供明确的采集步骤，不猜测服务端配置。
