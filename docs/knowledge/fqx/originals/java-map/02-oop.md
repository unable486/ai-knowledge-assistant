# Java > 类与对象

来源：https://fqx.lx.ci/java-map/

变量只能描述数据，方法只能描述行为；类把两者放在一起，描述一种事物，对象是这种事物的具体实例。面向对象的重点不是语法，而是让每个类只负责一件事。

# Java > 类与对象 > 类是模板，对象是实例

来源：https://fqx.lx.ci/java-map/

类定义字段和方法，对象保存自己的状态并执行这些方法。

例如 `User` 类描述用户有哪些数据和行为，`new User()` 得到一个具体用户。构造方法负责创建对象时完成初始化。

# Java > 类与对象 > 封装：别让外部随便改内部状态

来源：https://fqx.lx.ci/java-map/

字段通常设为 `private`，外部通过公开方法使用对象。这样对象可以在修改状态前做校验，也可以在不影响调用方的情况下更换内部实现。

封装的核心不是多写 getter/setter，而是**把规则放在拥有数据的类里**。

# Java > 类与对象 > 继承：复用共同特征

来源：https://fqx.lx.ci/java-map/

子类可以继承父类的字段和方法，并重写行为。它适合明确的“是一个”关系，例如 Dog 是 Animal。

继承会让类之间强绑定，实际开发更常优先使用组合：一个对象**拥有**另一个对象，而不是为了复用几行代码硬继承。

# Java > 类与对象 > 多态：面向接口调用

来源：https://fqx.lx.ci/java-map/

同一个接口可以有多种实现，调用方只依赖接口，不依赖具体类。

例如业务层只依赖 `PaymentService`，运行时可以传入微信或支付宝实现。这样替换实现、写单元测试都会更容易。

# Java > 类与对象 > 接口和抽象类怎么选

来源：https://fqx.lx.ci/java-map/

**接口**描述“能做什么”，适合定义协作规则；**抽象类**描述“本质相同的一类东西”，还能保存共同状态和实现。

一个类只能继承一个父类，但可以实现多个接口，所以业务边界通常先用接口表达。

# Java > 类与对象 > ==、equals 和 hashCode

来源：https://fqx.lx.ci/java-map/

基本类型用 `==` 比值；对象的 `==` 比是不是同一个对象，`equals` 比业务内容是否相等。

如果重写 `equals`，必须一起重写 `hashCode`，否则对象放进 HashMap 或 HashSet 后可能查不到、去重失败。
